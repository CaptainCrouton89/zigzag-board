- **Fractional-key sort must use `<`/`>` (UTF-16), never `localeCompare`** — fractional-indexing produces uppercase-headed keys (e.g. `'Zz'`) for insertions before the smallest existing key; `localeCompare` sorts `'Zz'` after `'a0'` while `<` correctly sorts it before. Using `localeCompare` silently produces duplicate fractional keys on consecutive drag-to-top operations. This comparator must stay identical across `mutations.ts` and `snapshot.ts`.
- **Saga drops resolve against the global saga sibling list (`sagaSiblings`), not per-lane siblings** — `Board.tsx`'s `computeDropTarget` uses `getSagaCards(node).length` for rank computation across all saga lanes. Using `siblingsByLane` for a saga destination silently places the card at the wrong position (collapsed to the local lane's end).
